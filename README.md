# Responsive Portfolio Website

This is a personal responsive portfolio website showcasing skills, projects, and contact information.

## Features
- Fully responsive design
- Navigation menu with smooth scrolling
- Sections: Home, About, Skills, Projects, Contact
- Social media integration
- Contact form

## Technologies Used
- **HTML**: Structure of the website
- **CSS**: Styling and layout (stylesheet.css)
- **Boxicons**: Icons for social media and services

## File Structure
```
root/
│── index.html       # Main HTML file
│── stylesheet.css   # Stylesheet for design
│── images/          # Folder for images (profile, projects, etc.)
│── script.js        # Placeholder for JavaScript (future enhancements)
```

## Setup Instructions
1. Download or clone the repository.
2. Place all files in a project directory.
3. Open `index.html` in a web browser.

## Sections Overview
### Home
- Displays introduction and social media links.

### About
- A brief introduction about the individual.

### Skills
- Highlights UI/UX, Frontend, and Backend development skills.

### Projects
